## CodexMate 2.0.0-alpha.4

### 本次更新
- 协作方加入房间后选择本地工作目录，自动克隆共享仓库并补齐 Git 配置；非空目录使用独立子目录，保留已有文件。
- 输入框左下角新增模型与思考强度选择，读取本机 Codex 可用选项，下一轮生效。
- 中断后保留原会话、Codex 线程和工作树，发送新消息即可继续；永久结束作为独立操作。
- 同伴状态显示仓库准备、授权、执行及暂停原因；准备完成后继续处理积压消息，修复中断期间的竞态。

### 升级说明
- **双方客户端与中转必须一起升级，本版使用中转协议 2。** 自建中转请拉取 main 最新代码并重新构建部署。
- 私有 Git 仓库仍使用各自机器的访问凭据；不会复制同伴账号或密钥。
- Windows 用户运行新版安装程序覆盖原安装目录，会话与工作树存放在用户数据目录。Mac 用户用新版应用替换旧版。
- 已被旧版永久取消的任务不会自动恢复；新版本的中断操作可以在原会话继续。

### 安装包与验证
提供 Windows x64 EXE、macOS arm64 DMG、macOS x64 DMG，以及 SHA256SUMS.txt。
各平台安装包在原生 GitHub Actions runner 上构建并完成安装/挂载、架构、桌面启动和捆绑 Codex 检查后才发布。
自动化覆盖真实 Git 与本机 WebSocket 的双客户端协作；Windows↔macOS 双实体设备、双账号完整任务仍待实测。

本版保持 alpha 预发布状态；安装包未代码签名，macOS 未公证。核对 SHA-256 后安装，系统可能显示开发者验证提示。
