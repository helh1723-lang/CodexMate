# 开始这段协作

两个人，两台机器，两个独立 Codex 账号，一个共享 Git 仓库。客户端不需要公网 IP；双方需要共同可达的 HTTPS 中转和 Git 远端。

## 获取客户端

从 [GitHub Releases](https://github.com/helh1723-lang/CodexMate/releases) 下载对应系统的安装包：Windows x64 选择 `.exe`；Apple silicon Mac 选择 `macOS-arm64.dmg`；Intel Mac 选择 `macOS-x64.dmg`。安装包包含 Electron 和 Codex CLI，不需要另外安装 Node.js；每台电脑需要系统 Git。源码运行则需要 Node.js ≥ 22.13。

下载后先对照 Release 的 `SHA256SUMS.txt` 校验安装包。Windows 双击 `.exe`，按向导选择安装位置。Mac 在“关于本机”查看芯片型号，打开对应 DMG，把 CodexMate 拖进“应用程序”，再从“应用程序”启动。

当前 alpha 包尚未代码签名，macOS 包也未公证，系统会显示开发者验证提示。Windows SmartScreen 提示未知发布者时，只在确认来源和校验值后继续。Mac 首次尝试打开后，如 Gatekeeper 阻止启动，可打开“系统设置 → 隐私与安全性”，在安全性区域点击“仍要打开”，再确认弹窗。操作步骤见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 前置

| 项 | 要求 |
|---|---|
| Node.js | 只在从源码启动时需要，≥ 22.13 |
| Codex | 安装包附带固定 CLI；在应用设置里登录自己的账号 |
| Git | 可用，且共享仓库的 `origin` **不含明文凭据**（使用凭据管理器，不在 HTTPS 地址中嵌入账号密码） |
| 中转服务 | 双方都能连到的一个地址（见下） |

## 0. 部署中转

两边选一台机器或用一台云主机：

```bash
# 本机 / 自建服务器
docker compose -f templates/relay/compose.yaml up -d
```

Caddy 会自动签发证书，因此需要先设置 `RELAY_DOMAIN`，域名解析到这台机器，且 80/443 可达。完整命令见 [部署指南](operations.md)。

本机测试运行 `npm run relay -- --home .local/relay --port 8787`，两个本地测试客户端填 `http://127.0.0.1:8787`。不同电脑不能用此地址互连。

## 1. 两边各自打开 CodexMate

```bash
npm install && npm run build && npm run desktop
```

打开后点击左下角「设置」或首页「连接我的协作空间」，按顺序完成四步。

### 第一步：连接我的 Codex

点「检测本机登录」。未登录则点「登录 Codex」，会在系统浏览器完成，回到应用再检测一次。

> 这里用的是**你自己的账号和额度**。同伴用的是他自己的。互不侵占。

### 第二步：选择共享 Git 仓库

两边都指向**同一个远端**的本地克隆。选好后填「项目检查命令」，例如：

```json
[["npm", "test"], ["npm", "run", "typecheck"]]
```

命令以参数数组书写，**不经过 shell 拼接**。每次提交前会自动跑，任何一条失败就不允许提交。

### 第三步：连接同伴

- **A** 填中转地址，点「创建房间」，拿到一串邀请码，发给 B（24 小时内有效）。
- **B** 填同一个地址，粘贴邀请码，点「加入房间」。

房间只允许两名成员。状态栏出现「同伴 · 在线」即为连上。

### 第四步：授权协作

两边都要点「授权这个项目和同伴」。这一步显式确认：**允许此同伴在当前项目的协作工作树内活动**。未授权时不会有任何自动行为。

## 2. 开始一件事

在输入框直接描述目标，回车发送。

之后是两个 Codex 自己的事了：它们会商量分工、各自写代码、各自跑检查、各自提交到 `cm/` 分支，再由发起方整合并交给同伴交叉审查。**你不需要干涉，但随时可以。**

### 随时可以做的事

| 情况 | 操作 |
|---|---|
| 想到补充要求 | 直接打字发送：执行中会插入当前轮次，空闲时作为下一轮 |
| 想要同伴立刻知道你的进展 | 点「同步上下文」 |
| Codex 申请额外权限 | 界面上会弹出请求，允许/拒绝由你决定 |
| 卡住了 | 任务会「暂停」并显示原因，检查后可继续（会追加唤醒预算） |
| 不想要了 | 点停止按钮：工作树和改动保留，同伴侧也会收到停止 |

## 3. 收尾

完成后成果在 `cm/<任务>/<成员>-*` 分支上。**主分支不会被自动改动。**

```bash
git fetch origin
git diff origin/main...origin/cm/<任务>/...   # 先看清楚
```

确认无误后由你自己合并。CodexMate 不替你合并，也不替你部署。

## 出问题先看这里

| 现象 | 原因 |
|---|---|
| 「同伴离线」一直不消失 | 中转地址不对 / 端口未放行 / 对方没上线。设置里有最近连接信息 |
| 「双方仓库 origin 不匹配」 | 确认是同一仓库；常见 git@host:path、ssh://git@host/path 和 HTTPS 形式会自动规范化 |
| 「请先推送项目基准提交」 | 你当前 HEAD 还没同步到远端，先 `git push` |
| Codex 提示额度或限流 | 本机 Codex 自身的额度问题，和 CodexMate 无关，界面显示「未知」而不是瞎猜 |
| 重启后任务变「已暂停」 | 执行状态不确定时先暂停，检查工作树、已有提交和记录后再继续 |
