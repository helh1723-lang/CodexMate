# 当前产品要求与核对范围

用户确认目标：在极简聊天界面输入一次任务，两台电脑使用各自的 Codex 登录和额度自动沟通、分工、执行，在独立集成工作树交付共同结果。

界面保留会话历史、项目与双端状态、消息、折叠协作/终端/差异、发送和停止；浅色、深色、跟随系统。首次登录 → 仓库 → 房间 → 项目授权。退出 Issue、看板、审批列表与原工作台主流程。

一房两人、一个共享项目、一个活动任务。普通读写、约定检查、cm/ 分支提交同步由一次授权覆盖；新增权限在所属设备对话中确认。主分支合并、强推、部署和仓库外操作不被普通协作授权覆盖。

Codex App Server 提供真实持久线程、流式输出、steer、interrupt 和权限请求；双方显式协作工具驱动消息，普通状态不自动唤醒。中转须提供认证、持久投递、去重、重连和取消优先恢复。

交付必须有双方提交、整合结果、实际检查和同伴精确 SHA 审查；用户补充后不得用过期审查完成任务。预算默认每端 20 次；不确定重启先暂停对账，取消终态不恢复旧任务。

本轮复查修复见 [progress.md](progress.md)。是否达到全部要求以 [acceptance.md](acceptance.md) 为准，尤其保留三组双机实测门槛，不能用真实单机模型或模拟 Agent 代替。
